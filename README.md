# AI CallAssist React Frontend

A modern React application for AI CallAssist - Professional AI-powered
appointment booking solution.

## 🚀 Features

- ⚛️ **React 18** with TypeScript
- 🎨 **Styled Components** for styling
- 🛣️ **React Router** for navigation
- 📱 **Responsive design**
- 🎯 **Component-based architecture**
- 🔄 **Modern React hooks**

## 📦 Installation

1. Navigate to the React frontend directory:

```bash
cd react-frontend
```

2. Install dependencies:

```bash
npm install
```

## 🏃‍♂️ Running the Application

### Development Server

```bash
npm start
```

Opens the app in development mode at
[http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
npm run build
```

Builds the app for production to the `build` folder.

### Run Tests

```bash
npm test
```

Launches the test runner in interactive watch mode.

## 🎨 Styling

This project uses **Styled Components** for styling, providing:

- Component-scoped CSS
- Dynamic styling with props
- Theme support
- CSS-in-JS benefits

## 🧭 Navigation

The app uses **React Router** for client-side routing:

- `/` or `/home` - Home page
- `/features` - Features page
- `/pricing` - Pricing page
- `/reviews` - Reviews page
- `/faq` - FAQ page
- `/contact` - Contact page
